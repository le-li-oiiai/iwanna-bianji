# I Wanna Shoot · 关卡编辑器

双击 `index.html` 即可使用（纯前端，不需要服务器）。

## 文件结构

```
2版小游戏编辑器/
├─ index.html                 页面骨架：只有 DOM 结构和 <link>/<script> 引用
├─ css/editor.css             编辑器样式
├─ templates/
│  └─ game-template.js        「测试游玩 / 导出 HTML」用的独立游戏页面（一个字符串常量）
└─ js/
   ├─ core.js                 默认关卡、工具表、武器常量、编辑状态 ed、撤销栈、坐标换算、实体增删、视图缩放
   ├─ draw.js                 画布渲染（网格、实体、选中框、拖拽预览）+ 有变化才重绘的主循环
   ├─ inspector.js            左侧工具栏、右侧属性面板、对象列表、世界设置（含初始武器）
   ├─ level-io.js             保存/加载 JSON、生成并导出 HTML、测试游玩
   ├─ pointer.js              画布上的鼠标操作（框选、拖动、缩放、绘制）和快捷键
   └─ main.js                 启动：绑定按钮、初始化视图
```

编辑器内部把函数统一挂在 `window.EDITOR` 上（代码里简写 `E`），所以各文件之间用 `E.xxx()` 互相调用；
`level`（关卡数据）、`ed`（编辑状态）、`history`（撤销栈）这些对象在各文件里共享同一份。

## 能放哪些东西

| 工具 | 快捷键 | 可调参数 |
| --- | --- | --- |
| 选择 / 移动 | `1` | — |
| 实体方块 | `2` | 尺寸、形变、碰撞箱 |
| 移动平台 | `3` | 振幅/轨迹、形变、碰撞箱 |
| 普通尖刺 | `4` | 尺寸 |
| 自设尖刺 | `0` | 伤害、形状、隐身、轨迹、形变、碰撞箱 |
| 巡逻敌人 / 射击敌人 | `5` / `6` | 血量、伤害、范围/间隔、轨迹、碰撞箱 |
| **血包** | `H` | **回复量**、**轨迹**、尺寸 |
| **武器** | `W` | **武器类型**（突击/霰弹/狙击）、**伤害**、轨迹、尺寸 |
| 接触存档点 / 自动存档点 | `7` / `T` | 尺寸、重生点 |
| 终点 | `8` | 尺寸 |
| 橡皮擦 | `9` | — |

左侧「初始武器」面板可以配玩家开局的两把武器（类型 + 伤害）；留「无」就是空手。

## 想改东西去哪儿

| 想改什么 | 改哪个文件 |
| --- | --- |
| 工具栏里的工具列表、默认尺寸、武器常量 | `js/core.js` |
| 属性面板的字段和选项 | `js/inspector.js` |
| 实体在编辑器里的画法 | `js/draw.js` |
| 拖拽/框选/缩放的手感 | `js/pointer.js` |
| 导出的游戏画面与玩法 | `templates/game-template.js` |
| 导出/保存的文件名、流程 | `js/level-io.js` |

## 关于导出模板（重要）

`templates/game-template.js` 里放着**一整套独立的游戏引擎**（导出的 HTML 自己就能玩，不依赖别处）。
所以：

- 改了游戏本体的玩法（比如武器手感、拾取规则），**要同步改这个模板**，否则「测试游玩」和导出的成品对不上。
- 关卡数据由 `js/level-io.js` 拼进模板的 `/*__LEVEL_DATA__*/` 位置，新增字段时两边都要加：
  - `level-io.js` 的 `serializeLevel()` / `generateGameHTML()` / `loadJSON()`
  - 模板里对应数组的初始化（例如血包的 `active`、武器的 `alive` 这类运行期状态）

> 改模板时注意：它是一段模板字符串，里面的反引号、`${`、反斜杠都需要转义。
> 改完点一次「测试游玩」，看看导出的成品是否正常。
